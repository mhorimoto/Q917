# Q917B UECS SIMULATOR - リモート操作ガイド (`q917sim.sh` 版)

このガイドでは，Linux端末からリモートで `q917sim.sh` スクリプトを使用して，Arduino（Q917B UECS SIMULATOR）ノードの状態取得や設定を行う方法について説明します．

## 必要な環境

* **socat**: コマンドラインからネットワーク通信を行うツールです．インストールされていない場合は，各ディストリビューションのパッケージマネージャからインストールしてください．
```bash
# Debian/Ubuntu系の場合
sudo apt install socat

```



---

## 基本的な使い方

スクリプト `q917sim.sh` を実行する際は，コマンドの第1引数に対象となるシミュレータの **IPアドレス** を必ず指定します．

```bash
./q917sim.sh [シミュレータのIPアドレス] [コマンド] [追加引数...]

```

### 1. バージョン情報の確認 (`ver`)

シミュレータのプログラム名称やバージョン番号を表示します．

* **コマンド**:
```bash
./q917sim.sh 192.168.38.104 ver

```


* **実行結果の例**:
```text
Q917B Ver:2.15  

```



### 2. EEPROMメモリマップのダンプ (`dump`)

シミュレータのEEPROMメモリの内容を指定されたブロック（256バイト単位，0〜3）で綺麗に表形式でダンプします．ブロックを省略した場合は自動的に `0` ブロック目になります．

* **コマンド**:
```bash
./q917sim.sh 192.168.38.104 dump 0

```


* **実行結果の例**:
```text
 ADDR | 00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F |0123456789ABCDEF
------+-------------------------------------------------+----------------
 0000 | 10 10 0C 00 00 0C 02 A2 73 0C 00 03 FF FF FF FF |........s.......
 0010 | 54 01 01 01 00 0F 0A 49 6E 41 69 72 54 65 6D 70 |T......InAirTemp
 ...

```



### 3. UECSパラメータの一括設定 (`set`)

各センサのUECS用送信パラメータを一括で書き換えます．桁数合わせや16進数（ヘキサ）への手動変換はスクリプトが自動で行うため，普段使いの10進数をそのまま入力可能です．

* **書式**:
```bash
./q917sim.sh [IPアドレス] set [ベースアドレス] [Room] [Region] [Order] [Priority] [Interval] [CCM型式名]

```


*(※ベースアドレス: `10`=温度, `30`=湿度, `50`=照度, `70`=CO2, `90`=cnd)*
* **コマンド例（温度を「Room 2，Region 1，Order 300，Priority 10，Interval 15，型式名 InAirTemp」に変更）**:
```bash
./q917sim.sh 192.168.38.104 set 10 2 1 300 10 15 InAirTemp

```


*(Orderは2バイト変数のため，スクリプト内で自動的に `012C` のように4桁ヘキサへと整形され安全に書き込まれます)*

### 4. 任意の個別コマンド直接送信 (`raw`)

1バイト個別のEEPROM書き換え（`S` コマンドなど）を直感的に実行するための万能コマンドです．

* **コマンド例（`DEMO_MODE_ADDR`（0x0F0）に値 `05`（5分タイマー）を設定する場合）**:
```bash
./q917sim.sh 192.168.38.104 raw S0F005

```


*(タイムアウトを自動無効化したい場合は `S0F000` または `S0F0FF` を送信します)*

### 5. マイコンのソフトリセット (`reset`)

設定を確実に初期化したいときや，再起動をかけたいときにリモートから安全にシミュレータをリセットします．

* **コマンド**:
```bash
./q917sim.sh 192.168.38.104 reset

```
